# THE CASE — القضية

لعبة تحقيق وغموض سينمائية باللغة العربية، بواجهة من اليمين إلى اليسار.

## الحالة الحالية
**النسخة التأسيسية 0.1 — واجهة البداية**

- صفحة رئيسية عربية متجاوبة.
- انتقال من القائمة إلى ملخص القضية ثم مكتب آدم.
- نافذة أرشيف القضايا.
- إعداد تشغيل/إيقاف المؤثرات الصوتية البسيطة.
- هوية أولية وأيقونة SVG داخل المشروع.
- ملف Web App Manifest.

## التشغيل
افتح `index.html` في متصفح حديث، أو انشر المستودع عبر GitHub Pages من إعدادات المستودع:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## البنية
- `index.html` — هيكل الواجهات.
- `styles.css` — الهوية البصرية والتصميم المتجاوب.
- `app.js` — تفاعلات الواجهة والصوت.
- `manifest.webmanifest` — تعريف تطبيق الويب.
- `assets/icons/app-icon.svg` — أيقونة المشروع.

## ملاحظات التطوير
هذه نسخة واجهة أولية وليست اللعبة الكاملة بعد. ستُضاف أنظمة التحقيق، الأدلة، الحوارات، الحفظ، الرسومات والصوتيات المرخصة على مراحل. لا تُعد عناصر الواجهة المقفلة محتوى لعب مكتملًا.

## التقنية
HTML · CSS · JavaScript — مع خطة تغليف لاحقة لتطبيق Android عبر Capacitor.
